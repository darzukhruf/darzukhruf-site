# موقع دار زخرف

موقع ثابت بدون أدوات بناء، ينشره Netlify تلقائياً من فرع `main`.

| الملف | المحتوى |
| :--- | :--- |
| `index.html` | الصفحة الرئيسية ونموذج "سجّل طلبك" (Netlify Forms) |
| `privacy.html` | سياسة الخصوصية |
| `assets/` | الشعار وصورة المشاركة |
| `netlify.toml` | إعدادات النشر |

رقم واتساب الأعمال يُضاف في `WA_NUMBER` داخل `index.html`، وزر واتساب يظهر تلقائياً بعدها.

الرابط: https://darzukhruf.netlify.app
